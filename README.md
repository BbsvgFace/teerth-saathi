# Teerth Saathi: case study

Portfolio case study for **Teerth Saathi**, a mobile prototype exploring coordination and incident response at the Kumbh Mela (Salesforce Hackathon, IIT Kanpur, 2-day design challenge). It will live on [bhargavramch.com](https://bhargavramch.com).

## What's here

| Folder | Contents |
| --- | --- |
| `site/` | The case study page: `index.html` plus `assets/`. Open `site/index.html` in a browser. This is the source to edit. |
| `single-file/` | The same page with every image and clip packed into one HTML file (images compressed). Handy for previews and sharing. |
| `framer/lanyard/` | Front and back faces for the Framer Lanyard component (`frontImage`, `backImage`). |
| `source/` | Original inputs: the visual design exploration graphics, the IA chart and the "under stress" workflow PDF. |

## Page structure

Six chapters, each opening with a numbered label:

1. **Context**: Kumbh Mela, what is happening, who we are aiding
2. **Problem**: problem statement (with the 48-hour scroll timer and lanyard), setting the stage, who reports to whom, constraints, research wall
3. **Research**: stakeholders (orbit), persona and empathy map, product goals
4. **Ideation**: information architecture chart, wireframes (pinned horizontal scroll)
5. **Design**: accessibility bento, visual explorations, design system, workflow map (zoom and pan)
6. **Solution and interactive prototype**: HTML prototype, features with prototype recordings, user testing

## Notes

- Type and sizing follow the Hold Up case study (Figtree, 880px reading column, 1120px breakouts). The opening follows Re-Routing Devotion.
- The interactive prototype is rebuilt in HTML from the final Figma screens. The two feature clips (`clip-alert.mp4`, `clip-profile.mp4`) are recordings of it.
- The design-system images (`ds-11` to `ds-15`) are still low resolution. Replace them with 2× or 3× exports from Figma.
